# Автоархивация тредов для DeepSeek Harness

Плагин скрывает неактивные треды штатной архивацией Harness. Данные и логи не удаляются, собственные архивации можно отменить. Вызовов модели нет.

## Установка из GitHub

В менеджере плагинов Harness укажите источник установки:

```text
https://github.com/the-evgenii/dsh-thread-archive.git
```

Через инструмент агента `plugin_manager`:

```json
{
  "action": "install_bundle",
  "target": "https://github.com/the-evgenii/dsh-thread-archive.git"
}
```

Пакет содержит готовые Host- и Client-файлы; сборка и install-скрипты не нужны. Установка включает плагин в текущем профиле. Страница находится в **Настройки → Автоархивация**.

Совместимость: **DeepSeek Harness 0.2.2-rc.1**, Node.js **24+**. Версии вне этого диапазона не заявлены совместимыми. `@local/dsh-thread-archive` — имя пакета, а не адрес в npm: устанавливайте по GitHub URL выше.

Источник Git фиксируется менеджером пакетов на конкретном коммите. Новые коммиты не загружаются автоматически; для обновления повторите установку из того же URL. Состояние плагина хранится отдельно от установленного пакета.

## Настройки

По умолчанию автоматика выключена: **14 дней** неактивности, проверка каждые **60 минут**. Выберите срок и исключения, включите переключатель и нажмите **Сохранить настройки**. Порог и исключения можно менять без отключения автоматики.

Сохранение не архивирует треды немедленно. При включённой автоматике проверка запускается через заданный интервал после загрузки плагина или сохранения настроек и повторяется с этим интервалом.

- Срок неактивности: от 1 до 3650 дней.
- Интервал проверки: от 5 до 1440 минут.
- Закреплённые треды пропускаются, если включена соответствующая настройка.
- Список проектов берётся из рабочих пространств Harness; исключение папки распространяется на её подпапки.
- Язык: русский, английский или язык Harness; для остальных языков используется английский.

## Защита и восстановление

Из архивации исключаются открытые/активные треды, дочерние агенты, защищённые треды и выбранные проекты. Непосредственно перед архивацией повторно проверяются активность и закрепление; текущая активность не останавливается.

Последние 300 записей доступны в истории. Восстановить можно только собственные успешные архивации плагина. После восстановления применяется новый период ожидания, равный настроенному сроку неактивности.

Инструмент `local_auto_archive` предоставляет действия:

| Действие | Назначение |
| --- | --- |
| `status` | Настройки, проекты, защищённые треды и история. |
| `save` | Сохранение переданных полей без сброса остальных настроек и без немедленной архивации. |
| `archive` | Ручная архивация сейчас по сохранённым настройкам. |
| `protect` | Установка или снятие защиты конкретного треда. |
| `undo` | Восстановление своей записи архивации. |

Для изменяющих действий нужна актуальная `revision` из `status`. На странице нет отдельной кнопки ручного запуска; защита задаётся инструментом, снять её можно также на странице. Предварительные просмотры и подтверждающие токены не используются.

Состояние хранится в `$DSH_HOME/state/local-auto-archive/state.json` (по умолчанию `~/.dsh/state/local-auto-archive/state.json`). Не публикуйте этот файл: он содержит настройки и историю ваших тредов.

## Разработка и проверки

```sh
npm run check
npm test
npm pack --dry-run --ignore-scripts
```

Обычные тесты используют стандартные модули Node.js и не требуют установки зависимостей. Интеграционный тест с установленным Harness по умолчанию пропускается. Для macOS Desktop:

```sh
DSH_RUNTIME_TESTS=1 ELECTRON_RUN_AS_NODE=1 \
  "/Applications/DeepSeek Harness.app/Contents/MacOS/DeepSeek Harness" \
  --test test/*.test.js
```

Для распакованного установленного runtime можно задать его каталог:

```sh
DSH_RUNTIME_TESTS=1 DSH_RUNTIME_DIR=/absolute/path/to/dsh \
  node --test test/*.test.js
```

Интеграционный тест создаёт изолированное временное состояние; пользовательские треды не изменяет.
